
1-Creating a New Recipe

User                  Frontend                      Backend                   Database
 |                       |                             |                          |
 |-- Clicks "Add Recipe"->|                             |                          |
 |                       |-- Renders input form ------->|                          |
 |-- Enters data & ----->|                             |                          |
 |   clicks "Save"       |-- POST /recipes ----------->|                          |
 |                       |   (recipe payload)          |-- Validates input & ---->|
 |                       |                             |   persists record        |
 |                       |                             |<-- Confirms insertion ---|
 |                       |<-- HTTP 201 Created --------|                          |
 |                       |   (returns new object)      |                          |
 |<-- Renders updated ---|                             |                          |
     recipe list         |                             |                          |



2: Viewing a Specific Recipe


     User                  Frontend                      Backend                   Database
 |                       |                             |                          |
 |-- Selects a recipe -->|                             |                          |
 |                       |-- GET /recipes/:id -------->|                          |
 |                       |                             |-- Queries record by ID ->|
 |                       |                             |<-- Returns recipe data --|
 |                       |                             |                          |
 |                       |    [Success Path]           |                          |
 |                       |<-- HTTP 200 OK -------------|                          |
 |                       |                             |                          |
 |                       |    [Error Path - Not Found] |                          |
 |                       |<-- HTTP 404 Not Found ------|                          |
 |                       |                             |                          |
 |<-- Displays details --|                             |                          |
     (or error state)    |                             |                          |

     User                  Frontend                      Backend                   Database
